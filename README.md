# Flask Starter Project

This is a minimal Flask starter codebase.

## Features
- Flask backend
- HTML frontend
- Simple in-memory storage

## Setup

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\\Scripts\\activate
pip install flask
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
